# What Is an AI Chatbot?

## Definition

An AI chatbot is a software application that uses
artificial intelligence to understand user messages
and generate relevant responses.

## Examples

- ChatGPT
- Google Gemini
- Microsoft Copilot

## Practical Example

A student asks an AI chatbot to explain a Java
program. The chatbot provides an explanation and
can answer follow-up questions.

## My Notes

AI chatbots can help users learn and solve problems.
However, their responses should be checked because
they may sometimes provide incorrect information.
