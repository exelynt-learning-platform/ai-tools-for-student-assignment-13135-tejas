# Same Question, Three AI Chatbots

## Prompt (identical for all three tools)

> I am a final-year computer science student interested in becoming a software developer in India. What does a software developer do day to day, which skills should I build in the next 6 months, and what is a realistic starting salary range for a fresher? Please keep it under 300 words.

## ChatGPT

### Software Developer Career Guide – India

As a final-year Computer Science student, becoming a software developer is a practical career goal. Here's what you should focus on.

**1. What does a software developer do daily?**

A software developer designs, builds, tests, and maintains software applications.

Typical daily activities include:
- Writing and debugging code.
- Developing frontend interfaces or backend APIs.
- Working with databases and application logic.
- Reviewing code and collaborating with teammates.
- Fixing bugs, attending meetings, and deploying applications.

**2. Skills to build in the next 6 months**

| Month | Focus |
|-------|-------|
| 1 | JavaScript/Java fundamentals, OOP, Git |
| 2 | Data Structures and Algorithms (arrays, strings, linked lists, trees) |
| 3 | React, HTML, CSS, TypeScript |
| 4 | Node.js, REST APIs, SQL, authentication |
| 5 | Build 2 real-world projects and deploy them |
| 6 | Interview preparation, resume improvement, mock interviews |

Important: Learn one technology stack deeply rather than switching between multiple frameworks.

**3. Realistic starting salary in India**

For a fresher in 2026, a practical starting salary range is approximately ₹3–6 LPA (₹25,000–₹50,000 monthly CTC equivalent). Strong candidates at product companies may receive ₹8–15 LPA or more, but these roles are highly competitive. (Source shown by ChatGPT: Indeed +2)

Salary depends on your skills, interview performance, location, and company type.

My advice: Focus on becoming job-ready rather than chasing a high salary immediately. Strong fundamentals, practical projects, and consistent DSA practice will improve your chances of getting a good first job.

## Claude

(Answered by Claude Sonnet 5.5 via Claude Code, unedited.)

**What a software developer does day to day**
You write and review code, fix bugs, and turn requirements into working features. Typical days include a short stand-up meeting, coding or debugging, writing tests, code review with teammates, and reading documentation or logs when something breaks. Much of the job is communication: clarifying requirements and explaining your changes.

**Skills to build in the next 6 months**
1. One main language in depth (Java, Python or JavaScript) plus data structures and algorithms for interviews.
2. Git and GitHub, used daily, with branches and pull requests.
3. SQL and one database, plus building a small REST API with a framework (Spring Boot, Django or Node/Express).
4. Basic testing, debugging, and reading other people's code.
5. Two or three real projects on GitHub with clear READMEs, and basic cloud and Linux familiarity.
6. Using AI tools well, while still being able to check and understand what they produce.

**Realistic fresher salary in India**
It varies a lot by company type and city. Service companies commonly start around 3 to 6 lakh per year, mid-size and product companies around 6 to 12 lakh, and top product companies and startups can go well above that. Treat these as rough ranges and check recent offers on sites like Glassdoor or LinkedIn.

## Gemini

### Day-to-Day Responsibilities

A software developer's day involves much more than just writing code:

- **Writing & Reviewing Code:** Feature development using languages like Java, Python, or JavaScript.
- **Debugging & Maintenance:** Identifying, tracing, and fixing software bugs or system bottlenecks.
- **Team Collaboration:** Attending daily Agile/Scrum standups, discussing architecture, and completing peer code reviews.
- **Testing & Deployment:** Writing unit tests and pushing code to production via automated pipelines (CI/CD).

### Skills to Build in the Next 6 Months

- **Core Data Structures & Algorithms (DSA):** Master array, string, tree, and graph patterns to clear technical coding rounds.
- **One Full Tech Stack:** Pick a core language (Java, Python, or JavaScript/TypeScript) and learn a relevant framework (Node.js, Spring Boot, or React).
- **Databases:** Build comfort with SQL (PostgreSQL/MySQL) and basic schema design.
- **Developer Tools:** Master Git version control (branching, PRs) and basic Linux command-line operations.
- **AI-Assisted Coding:** Practice leveraging AI coding assistants (e.g., GitHub Copilot, ChatGPT) for debugging and boilerplate setup to boost productivity.

### Realistic Starting Salary Range in India

Starting packages for freshers depend heavily on the type of employer:
